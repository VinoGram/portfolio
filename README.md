# High-End Animation Portfolio
  
This is a frontend-only React project built with [Vite](https://vitejs.dev/) and styled with Tailwind CSS.
  
## Project structure
  
The frontend code is in the `src` directory and is built with [Vite](https://vitejs.dev/).
  
`npm run dev` will start the development server.

## Developing your app

* Run `npm install` to install dependencies
* Run `npm run dev` to start the development server
* Run `npm run build` to build for production
